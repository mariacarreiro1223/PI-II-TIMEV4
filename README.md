## Instalações:
Necessário ter instalado VS Code, Node.js LTS. Após abrir a pasta raíz do projeto no VS Code, abra o terminal integrado e instale as dependências:
* **npm i express**

Iniciar a execução do servidor:
* **node .\lib\index.js**
